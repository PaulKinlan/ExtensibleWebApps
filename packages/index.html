Services

Give the app something new that other plugins use, such as a language model. A service draws nothing itself.

Language models

  • Claude (Anthropic) Service

    Answers the app's llm requests with Claude, using the person's Anthropic API key.

    • Provides the llm service
    • In Assistant, Librarian, Markdown editor, Security, Make an app
    Asks for 3 permissions
    • provide:llm Answer every call this page's plugins make to the llm service.
    • network:api.anthropic.com Connect to api.anthropic.com.
    • secret:anthropic Use a key you give it for anthropic, which it never sees: the site adds it to its requests.
