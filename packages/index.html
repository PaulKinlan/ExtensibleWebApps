Add any of these to any app, even one whose author never planned for it. Open the app (try the trip), open Customize in the bottom left, and pick one under Add a plugin. You see its code and what it asks for before it is added, it is kept on your device, and you turn it on when you're ready. A plugin that needs another, as World clock needs Clock, brings it along. How the registry works.

  • Ask the page

    Answers questions about this page with a language model, from the plugins it is made of.

    Asks for: ui, llm, plugins:read · A standard plugin

  • Board

    Questions from the app's agents, waiting for your answer, and what they did lately.

    Asks for: ui, bus:board, hook:listen:bus:asked, hook:listen:bus:answered, hook:listen:agent:* · A standard plugin

  • Clock

    Provides the clock service: the time now in any time zone.

    Asks for: provide:clock · Provides the clock service

  • Debug console

    A bug button that shows errors and the trace, ready to copy into a bug report.

    Asks for: ui, debug:read · A standard plugin

  • Hook tracer

    Shows each hook an action runs, in order, and what every plugin listening said.

    Asks for: ui, plugins:read, debug:read · A standard plugin

  • Import and export

    Buttons to save each of the app's collections to a CSV or JSON file, and to import a file's rows into one.

    Asks for: ui, transfer · A standard plugin

  • Reset

    Turns every plugin on the page back on.

    Asks for: ui, plugins:read, plugins:manage · A standard plugin

  • Switchboard

    A switch for each plugin on the page.

    Asks for: ui, plugins:read, plugins:manage · A standard plugin

  • Sync

    In a space: whether this page reaches it, and the versions of records it kept when someone else changed them first.

    Asks for: ui, sync · A standard plugin

  • Undo

    Undo and Redo buttons that take back the app's most recent change to its data, and put it back again.

    Asks for: ui, history · A standard plugin

  • View source

    Shows the code of every plugin on the page, and what each one may do.

    Asks for: ui, plugins:read · A standard plugin

  • World clock

    The time in London, New York and Tokyo, at the foot of the page.

    Asks for: ui, clock · Brings Clock, which it needs
